# 图色助手

在 VS Code 内通过 **ADB** 连接安卓设备/模拟器，一键截屏后在截图上**点击标记坐标并取色**，画面可**放大缩小与拖动**，并可按标记点或框选区域**裁剪小图、自动命名保存**。适合做自动化脚本前的坐标/找色素材整理。

## 功能

- 搜索设备（`adb devices`），弹窗选择设备；支持输入 `IP:端口` 连接模拟器（如 `127.0.0.1:1093`）
- 一键截取设备屏幕（`exec-out screencap -p`，原始 PNG，无 CRLF 损坏）
- 也可载入本地截图（png/jpg/jpeg/webp/bmp）进行标记
- **缩放与移动**：鼠标滚轮以光标位置为锚点放大/缩小（左下角工具条实时显示比例）；切到「拖动画面」模式用左键直接拖动，也可用中键、右键或按住空格拖动；双击画面或点「适配」回到窗口适配，点比例数字回到 100%
- 鼠标在截图上移动：
  - 全屏十字线
  - 跟随鼠标的**像素放大镜**（可配置网格边长，中心像素绿色高亮）
  - 实时显示**原图坐标**与该点颜色 `#hex`
- **点击标记**：在右侧表格记录「序号 / 坐标 / 颜色」，可选中、删除、清空
- **框选范围**：鼠标拖拽出矩形选区
- **获取设备控件**：`uiautomator dump` 拉取当前界面控件树，在截图上以紫色框叠加控件边界；默认只显示可交互控件（可点击/长按/滚动），可勾选显示全部节点；点击控件弹出信息卡（文本 / resource-id / content-desc / bounds / 中心坐标），可一键复制 ID、文本、坐标，或直接向设备点击该控件
- **截存小图**（弹出「另存为」对话框，文件名已自动生成，可自行改目录/文件名）：
  - 有框选时，按框选区域裁剪
  - 否则以选中（或最新）标记点为中心，按可配置边长（默认 64×64）裁剪，自动夹紧屏幕边界
  - **批量截存全部标记**：开始前弹一次目录选择，之后每个点一张小图存入该目录
- 保存整张截图（「另存为」对话框，自选位置）
- 按标记点生成点击代码并一键复制，支持三种格式（下拉切换，自动重新生成）：
  - **ADB 命令**：`adb -s <设备> shell input tap x y`
  - **颜色点击**：`zzCommonFunc.colorClickAdHandle('#颜色', true, { threshold: 4, region: [x, y, 50, 50] }, '#颜色', tempImag, pkgName, 1000, true, false)`
  - **绝对坐标**：`zzCommonFunc.clickAbsoluteLocation(x,y, '序号')`

## 准备

1. 安装 Android **platform-tools**，确保 `adb` 可用：
   ```bash
   adb version
   ```
   若 `adb` 不在 PATH 中，在设置里配置 `adbScreenshot.adbPath` 为完整路径。
2. 真机：开启「开发者选项 → USB 调试」并在弹窗中授权；模拟器：先启动模拟器，再用其 adb 端口连接。
3. 保存图片/小图时会弹出对话框，由你选择保存位置（对话框默认从工作区目录或上次选择的目录开始），不会静默写入默认目录。

## 使用

1. 命令面板执行 **「图色助手：打开工作台」**（或侧边栏命令搜索）
2. 点 **搜索设备** → 在弹窗中选择设备（也可输入地址点「连接」）→「连接设备」
3. 点 **截取屏幕**，画面出现后：
   - 滚轮缩放画面；切「拖动画面」用左键移动，或中键/右键/空格+左键拖动
   - 「点击标记」模式下，在目标位置单击即完成标记取色
   - 「框选范围」模式下，按住左键拖出矩形
4. 点 **获取控件**，画面上叠加紫色控件框（悬停显示名称，点击控件查看信息卡并可复制/直接点击）；勾选「显示全部控件」可查看不可点击节点
5. 点 **截存小图**，在弹窗中确认保存当前框选或选中点；点 **批量截存全部标记** 先选目录再一次保存所有点
6. 需要整图时点 **保存图片**；需要点击脚本时点 **生成代码 → 复制代码**

> 小提示：右侧表格点击某行可选中该标记（图上黄色高亮）；**右键某行弹出菜单**（复制坐标 / 复制颜色值 / 删除选中行 / 清空列表）；`Delete` 键删除选中标记，`Esc` 清除框选/选中或关闭右键菜单。
>
> 连续截图时，**右侧坐标列表会保留**（序号续编，便于跨画面累积采集、批量截存和生成 tap 代码），但画面上的旧标记点与框选会清空以保持新画面干净；点击表格任意一行，可在新画面上临时高亮定位该坐标。需要全部重来时点左侧「清空标记」。

## 自动命名规则（与截图内容相关）

文件名内嵌裁剪区域的**主色调**（对区域像素做量化直方图统计，取占比最高颜色的桶内平均色），相同画面内容颜色一致，便于按内容归类：

| 场景 | 文件名示例 |
| --- | --- |
| 以点为中心 | `crop_x650_y1197_338a3c_20260930-194149.png` |
| 框选区域 | `crop_r305_1485_200x100_b23e05_20260930-194149.png` |
| 重名 | 自动追加 `_1`、`_2` |
| 整屏保存 | `full_127.0.0.1_1093_20260930-194149.png` |

说明：坐标为**设备真实分辨率坐标**（可直接用于 `input tap`）；时间戳保证不覆盖。当前为完全离线的颜色特征命名；如需「按钮/卡牌」这类 AI 语义命名，需要额外接入图像识别服务。

## 配置项

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| `adbScreenshot.adbPath` | `adb` | adb 可执行文件路径 |
| `adbScreenshot.cropSize` | `64` | 以点为中心裁剪的小图边长（像素） |
| `adbScreenshot.filenamePrefix` | `crop` | 文件名前缀 |
| `adbScreenshot.magnifierPixels` | `15` | 放大镜像素网格边长（建议奇数） |
| `adbScreenshot.commandTimeout` | `30000` | adb 命令超时（毫秒）；截图/控件 dump 最低放宽到 60 秒 |

## 命令

- `图色助手：截取屏幕`
- `图色助手：选择/连接设备`

## 常见问题

- **未找到 adb**：确认已安装 platform-tools，或在设置中把 `adbScreenshot.adbPath` 配为完整路径。
- **设备状态是 unauthorized**：在设备屏幕上确认 USB 调试授权弹窗；或执行 `adb kill-server` 后重连。
- **设备状态是 offline**：重启模拟器/重新插拔数据线，再点「刷新」。
- **连接模拟器失败（Connection refused）**：确认模拟器已启动、端口正确（不同模拟器端口不同，常见如 5555/7555/1093/7463/3022 等）。
- **云手机 / 远程设备截图超时失败**：云手机画面走网络传输，旧版 `exec-out` 方式实测 2.4MB 画面要约 16 秒，超过 15 秒超时。0.3.1 起自动改用「设备端存图 + adb pull 拉取」（实测约 5 秒），失败再回退 exec-out，并把截图超时最低放宽到 60 秒；若你的链路更慢，在设置中把 `adbScreenshot.commandTimeout` 调大（如 `120000`）。
- **没有打开工作区**：保存对话框仍会弹出，可自行选择任意目录；选择过的目录会作为下次对话框的起始位置。
- **获取控件报错「could not get idle state」**：`uiautomator dump` 需要界面停止动画，游戏/持续动画界面可能等不到空闲而失败（系统工具无官方跳过参数）。等界面静止或切到原生界面再获取；游戏画面通常是自绘的，原生控件很少，此时仍可用点击标记/取色。
- **获取控件后重新截图/载入图片**：控件树会自动清空，避免紫色框与新画面错位；需要时重新点「获取控件」。
